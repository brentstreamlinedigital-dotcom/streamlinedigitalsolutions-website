# Doc 2 of 3: Streamline Rebrand Project Brief

**Goal:** Rebuild streamlinedigitalsolutions.com using Good Fella's page architecture and motion language, re-skinned and re-written as Streamline: an AI-native Ecomm Growth Engine based in Cape Town.

**Positioning shift**

| Good Fella | Streamline |
| --- | --- |
| Digital landmark studio | Ecomm Growth Engine |
| Consumer, sports, entertainment brands | Ecommerce brands (DTC, Shopify, scaling stores) |
| One service: custom frontend | Full stack: web, SEO, ads, CRM, apps, automation, AI |
| "Both brothers on every project" | Senior team, AI-accelerated delivery |
| Brand outcome (landmark) | Commercial outcome (revenue, ROAS, hours saved) |
| Scarcity, waitlist | Keep scarcity: limited growth partner slots per quarter |

**In scope:** 8 pages + case study template, new copy, new tokens, new hero art, forms wired, SEO, legal.

**Out of scope (Phase 2):** blog, AI chat widget demo, client portal login.

## 5. Build spec and plan

**Stack:** Next.js 14+ App Router, TypeScript, Tailwind, GSAP + ScrollTrigger, Lenis, Canvas 2D for ASCII art, Supabase (form data), Resend (email alerts), Vercel.

**Content:** case studies and FAQs as typed data files in /content (no CMS in Phase 1).

**Integrations**

- Contact form → Supabase table + Resend notification to Brent
- Newsletter → Supabase table (export to email tool later)
- Book a call → Google Calendar appointment schedule link
- Analytics → GA4 + Meta Pixel (consent gated)

**Content Brent must supply:** logo SVGs, real stats, 4 approved case studies (metrics + mockups), team photos, budget ranges, pricing tier sign-off, socials, legal copy review.

**Acceptance criteria (definition of done)**

- Zero Good Fella copy, images, logos or names anywhere (grep check)
- All 9 routes live, no console errors, no layout shift on load
- Lighthouse mobile: Performance 90+, Accessibility 95+, SEO 100
- WCAG AA contrast on every text pair
- Forms submit, store and email on production
- Reduced motion mode fully static and usable
- Unique title, description, OG image per page, sitemap.xml, robots.txt
- No em dashes in any copy

**Step by step (simple version)**

1. Approve this brief and fill every \[CONFIRM\] item.
2. Gather assets (logo, photos, case study numbers) into one Google Drive folder.
3. Create a new Next.js repo, paste the Doc 3 prompt into Antigravity or Claude Code.
4. Let the AI build Phase 1 (layout, pages, copy, tokens). Review on a Vercel preview.
5. Run Phase 2: motion and hero canvas polish in Antigravity.
6. Wire Supabase, Resend and the booking link. Test every form.
7. Run the acceptance checklist above. Fix anything that fails.
8. Point the domain to Vercel and launch.
